# 网页游戏解谜整理插件 (Web Puzzle Helper)

一款专为网页解谜、密室逃脱、文字冒险游戏设计的浏览器扩展。支持从游戏页面自动提取线索、整理时间线，并借助大模型进行推理提问。

## 功能特性

- **严格的隐私与权限模型**：遵循按需授权原则，默认不申请全网访问权限；API Key 仅保存在浏览器本地，绝不上报。
- **动态站点采集**：仅在用户显式添加的游戏域名下动态注入阅读器，避免对日常浏览造成干扰。
- **多模型支持**：支持 DeepSeek、OpenAI 兼容接口以及 Google Gemini。
- **轻量画布截图支持**：针对 HTML5 Canvas 画布游戏提供受限截屏（30 秒防刷节流）。

## 安装与开发指南

### 1. 在 Chrome 中加载扩展

1. 克隆或下载本仓库至本地目录。
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
3. 在右上角开启 **开发者模式**（Developer mode）。
4. 点击左上角的 **加载已解压的扩展程序**（Load unpacked），选择本项目的根目录。

### 2. 配置大模型与游戏网站

1. 在扩展图标上右键选择「选项」，或进入扩展管理页点击「详细信息」->「扩展程序选项」。
2. 选择模型供应商（如 `deepseek`、`openai_compatible` 或 `gemini`）。
3. 填入你的 API Key（例如测试占位符 `sk-TESTONLY_not_a_real_key_xxxx9999`）。请勿在此处输入生产核心密钥，且注意 DeepSeek 暂不支持直接图文解析。
4. 在「游戏授权网站」区域添加游戏主域名（例如 `https://example-puzzle-game.com`），此时浏览器会弹出跨域站点授权确认框。
5. 点击「保存设置」。

### 3. 使用侧边栏辅助解谜

1. 在被授权的游戏页面点击扩展图标，打开右侧边栏（Side Panel）。
2. 阅读器会周期性检测文本变动并生成提取线索。
3. 若为纯 Canvas 游戏，页面右下角将出现「发送截图解谜」悬浮按钮，支持单帧图像分析（内置 30 秒节流）。
4. 在侧边栏输入提问（如“根据我拿到的两把钥匙，书房柜子密码可能是什么？”），模型将结合捕获的线索进行分析并作答。
5. 可随时导出线索为 Markdown 或 JSON 保存复盘。

### 4. 运行自动化测试

本项目在 Node 18+ 环境下提供轻量无依赖的冒烟测试：

```bash
npm test
# 或直接运行
node tests/run.mjs
```

> **提示**：当前仓库包含完整的核心协议与运行骨架，页面文本高级清洗与后台复杂管线标注有部分 TODO，可按需扩展业务规则。
